# 🛒 Ecommerce React App

A modern, responsive ecommerce web application built using **React, TypeScript, Tailwind CSS**, and **REST APIs**.

## 🚀 Features
- User Authentication (Login & Register)
- Product Listing with Categories
- Product Details Page
- Add to Cart & Cart Management
- Orders Page
- Responsive UI (Mobile, Tablet, Desktop)
- Clean & Premium UI Design

## 🛠 Tech Stack
- React + TypeScript
- Tailwind CSS
- React Router
- Context API
- REST API Integration
- Vite
